# SEO Tracking Bundle 1.4.0

This additive release turns the first deliberately deferred roadmap items into safe, generic extension points: historical grouping repair, bounded retention and consent-aware tracking.

## Historical data lifecycle

- `zhortein:seo-tracking:backfill-grouping-keys` inventories historical null grouping keys without writing by default.
- Explicit apply and duplicate-consolidation modes are resumable and bounded by batch size.
- The default merger preserves hits and aggregate dates while custom entities require an application-owned merge policy.
- `zhortein:seo-tracking:purge` previews an opt-in retention policy before any deletion.
- Applied purges unlink affected parent hits portably, repair surviving aggregates and can remove newly emptied page calls only when explicitly requested.
- Undated hits are never deleted by the age policy.

## Consent hooks

- A replaceable `TrackingConsentCheckerInterface` is shared by the Twig helper and tracking endpoint.
- The backward-compatible default allows immediate tracking.
- Configurable, vendor-neutral grant and revoke events let an application integrate its own consent manager.
- Pending or revoked consent creates no new hit. Revocation closes an active or in-flight hit once and clears the browser flow link.
- A later grant starts a fresh flow without linking it to pre-revocation activity.
- The exit endpoint remains available to close a hit opened before consent was revoked.

The bundle does not choose a legal basis, cookie format, consent category, retention duration or erasure policy for the consuming application.

## Quality and compatibility

- PHPUnit covers command previews and apply modes, custom entities, rollback-sensitive aggregate behavior, consent denial and hit closure.
- Six Node scenarios cover immediate, pending, grant, revoke, Turbo and reconnect lifecycles.
- PHPStan runs at its maximum level without a baseline.
- CI covers PHP 8.3–8.5, Symfony 7.3–8.1, Node 22/24, SQLite, PostgreSQL 16 and MySQL 8.4.

## Update

```bash
composer require zhortein/seo-tracking-bundle:^1.4
php bin/console asset-map:compile
```

There is no Doctrine schema migration from 1.3. Backfill, consolidation, retention and consent gating remain opt-in. Read the full [upgrade and rollback procedure](https://github.com/Zhortein/seo-tracking-bundle/blob/1.4.0/docs/upgrade-1.4.md).

## Deliberately deferred

RateLimiter integration, advanced bot classification, invalid-event tracking, identity-dependent flow reports, application-defined metadata, high-volume caching/pre-aggregation, additional themes/charts, export adapters and a broader continuously tested database matrix remain in the roadmap.
