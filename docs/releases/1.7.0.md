# SEO Tracking Bundle 1.7.0

This additive release makes existing statistics easier to browse, cache, export and present without changing collection or introducing an identity model.

## Bounded navigation and opt-in cache

- `ObservationBrowserInterface` exposes filtered observation pages with non-negative offsets, a default size of 50 and a maximum size of 500.
- The default browser reads only the requested window plus one look-ahead observation.
- Applications can replace the browser with a database-specific cursor implementation when deep offsets are unsuitable.
- Aggregate report caching remains disabled until both a PSR-6 pool and a positive TTL are configured.
- Cache keys include every normalized filter, timezone, typed dimension, ranking limit and an internal schema version.
- Cache backend failures are fail-open: the report is computed rather than turning an optimization into an outage.

Neither pagination nor caching changes filter semantics, retention or the meaning of a report.

## Safe streaming CSV exports

- `CsvStatisticsExporterInterface` lazily exports the same filtered observations used by reports and pagination.
- The stable UTF-8 schema covers timestamps, bot and closure flags, duration, page context, UTM values, type, language and sorted dimensions.
- CSV dialect options validate delimiter, enclosure, LF or CRLF line endings and an optional UTF-8 BOM.
- Every field is enclosed, and formula-like string cells are prefixed safely before common spreadsheet software can interpret them.
- The bundle registers no public download route. Host applications retain authorization, filename, audit, rate-limit and retention control.

Exports include no raw IP address, User-Agent, visitor identifier or field absent from the typed observation.

## Accessible translated presentation

- Bootstrap 5 remains the backward-compatible default theme.
- A new `html5` theme emits semantic, dependency-free markup without loading CSS, JavaScript or remote assets.
- Both themes provide lightweight proportional rankings and trends while retaining exact textual counts and a complete daily table.
- Empty and zero-count reports use bounded values and never render division-by-zero, `NaN` or infinite dimensions.
- Bundled English and French catalogs use the `seo_tracking` translation domain.
- Both themes preserve the `summary`, `trend`, `rankings` and `dimensions` Twig blocks and remain fully overrideable.

These visuals describe page calls and hits only. They do not imply visitors, devices or stable sessions.

## Quality and compatibility

- PHPUnit covers filter-equivalent pagination and exports, lazy iteration, deterministic caches, backend failures, CSV injection, both themes, translations, escaping and zero-count rendering.
- Six Node scenarios continue to cover immediate, consent-aware, Turbo and reconnect lifecycles.
- PHPStan runs at its maximum level without a baseline.
- CI covers PHP 8.3–8.5, Symfony 7.3–8.1, Node 22/24, SQLite, PostgreSQL 16 and MySQL 8.4.
- No Doctrine schema migration is required.

## Update

```bash
composer require zhortein/seo-tracking-bundle:^1.7
php bin/console asset-map:compile
```

Existing applications keep their current Bootstrap presentation and uncached statistics unless they opt into a new feature. Read the full [upgrade and rollback procedure](https://github.com/Zhortein/seo-tracking-bundle/blob/1.7.0/docs/upgrade-1.7.md).

## Deliberately deferred

Identity-dependent metrics, authenticated or cross-device journeys, pre-aggregated high-volume storage, database-native cursor policies, non-CSV external analytics adapters and a broader continuously tested database matrix remain in the roadmap.
