# SEO Tracking Bundle 1.7.1

This patch release makes the complete 1.7 feature set easier to install,
understand and integrate. It also corrects generated configuration reference
output without changing runtime defaults, collection payloads or Doctrine
mappings.

## Complete onboarding

- The root README is now a concise project, compatibility and documentation
  landing page.
- A new end-to-end quick start covers bundle and route registration, Doctrine
  migration review, Stimulus/AssetMapper setup, browser and database
  verification, and a protected statistics page.
- A central documentation index links every collection, privacy, statistics,
  operations, upgrade and release guide.
- An application cookbook provides ready-to-adapt tracking, filtering,
  pagination, CSV, journey, event and presentation examples.

## Reference documentation

- Every public configuration option is documented with its default,
  validation and behavior.
- Replaceable entity, collection, statistics, cache, pagination, export,
  journey and lifecycle contracts are indexed.
- Dedicated guides describe the persisted data model, custom entities and the
  disabled-by-default historical Easylyse forwarding adapter.
- Privacy, authorization, migration, destructive-operation and external
  forwarding boundaries are stated alongside the relevant examples.
- Application-specific wording has been removed from the public historical
  release notes.

## Configuration reference fix

The internal configuration tree root now matches the public
`zhortein_seo_tracking` extension alias. This corrects the root displayed by
`config:dump-reference`; existing application YAML and runtime configuration
remain unchanged.

The public package description has also been corrected and now describes the
bundle's privacy-conscious page, campaign and engagement tracking scope.

## Quality and compatibility

- PHPUnit verifies that required guides exist, every topic is indexed, local
  Markdown links resolve and every processed configuration key is documented.
- The quick start is checked for its required installation and verification
  steps.
- The established PHP, Symfony, JavaScript and database compatibility matrix
  remains unchanged.
- No Doctrine migration, backfill or asset behavior change is required.

## Update

```bash
composer require zhortein/seo-tracking-bundle:^1.7
php bin/console asset-map:compile
```

Applications already using 1.7.0 need no configuration or database change.
Use the [documentation index](https://github.com/Zhortein/seo-tracking-bundle/blob/1.7.1/docs/index.md)
for the complete guide set and the existing
[1.7 upgrade procedure](https://github.com/Zhortein/seo-tracking-bundle/blob/1.7.1/docs/upgrade-1.7.md)
when upgrading from an older minor release.
