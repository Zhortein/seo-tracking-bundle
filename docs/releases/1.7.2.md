# SEO Tracking Bundle 1.7.2

This patch release restores page tracking when applications call the Twig
`seo_tracking()` helper without custom dimensions.

## Empty dimensions fix

The helper previously rendered an omitted dimensions map as the JSON array
`[]`. The distributed Stimulus controller declares `dimensions` as an `Object`
value, so Stimulus rejected the generated attribute before the controller could
send the page hit.

Empty dimensions are now rendered as the JSON object `{}`. Non-empty
application-defined dimensions keep the same normalization, validation and
payload behavior.

## Quality and compatibility

- Regression coverage verifies the generated empty object and prevents the
  invalid empty array from returning.
- The existing PHP, Symfony, JavaScript and database compatibility matrix is
  unchanged.
- No JavaScript controller, configuration or public API has changed.
- No Doctrine migration or data backfill is required.

## Update

```bash
composer require zhortein/seo-tracking-bundle:^1.7.2
php bin/console asset-map:compile
```

Clear the application cache and deploy the rebuilt asset map through the
application's normal release process. Existing custom dimensions and stored
tracking data remain compatible.
