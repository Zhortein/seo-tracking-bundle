# SEO Tracking Bundle 1.3.0

This additive release fixes the audited tracking defects, makes application-level extension points effective, and introduces the first typed statistics and Twig rendering API.

## Tracking fixes

- The distributed Stimulus controller is valid JavaScript.
- Classic pages, Turbo navigation, visibility changes and controller reconnection close and restart hits without accumulating listeners.
- `sendBeacon()` has a keepalive `fetch()` fallback, and missing JavaScript still degrades without blocking navigation.
- Tracking and exit URLs are configurable and generated from bundle routes by default.
- Configured `PageCall` and `PageCallHit` classes are used for repositories, creation, relations, exit handling and events; replaceable factories support required constructors.
- IPv4 and IPv6 anonymization prefixes are configurable.
- Canonical URLs group equivalent observations while each hit retains its observed URL.
- A deterministic grouping key provides functional uniqueness with nullable UTM fields on SQLite, PostgreSQL and MySQL.
- Payload validation, bot detection and hit closure are hardened.

## Statistics and Twig

- Typed filters, DTOs, data-source and provider interfaces keep calculations independent from presentation.
- Reliable metrics cover page calls, human/robot hits, closed-hit duration samples, popular pages, UTM dimensions, route, type, language and trends.
- Period, timezone, robot and page-type filters are generic and testable.
- Twig templates are overrideable. The bundled Bootstrap 5 theme is selectable or can be disabled; Bootstrap is not a runtime dependency.
- No “unique visitor” metric is exposed because the stored data cannot support that claim reliably.

## Quality and compatibility

- PHPUnit now covers services, controllers, custom entities, Twig rendering and database behavior.
- The Stimulus/Turbo lifecycle has a real Node test harness.
- PHPStan runs at its maximum level without a baseline.
- CI covers PHP 8.3–8.5, Symfony 7.3–8.1, Node 22/24, SQLite, PostgreSQL 16 and MySQL 8.4.

## Update

```bash
composer require zhortein/seo-tracking-bundle:^1.3
php bin/console doctrine:migrations:diff
php bin/console doctrine:migrations:migrate
php bin/console asset-map:compile
```

Review the generated migration before applying it. The default schema widens URL/referrer columns, adds canonical and observed URLs, and replaces the nullable UTM composite constraint with a nullable unique grouping key. Historical duplicates are preserved; consolidation and backfill are intentionally application policy.

Read the full [upgrade and rollback procedure](https://github.com/Zhortein/seo-tracking-bundle/blob/1.3.0/docs/upgrade-1.3.md).

## Removable application workarounds

Consuming applications can remove overrides that only repaired the former
invalid Stimulus file, hard-coded entity construction, IPv4-only
anonymization, endpoint/canonical limitations, or duplicate/unclosed Turbo
hits. Keep application-specific consent, retention, authorization, enrichment
and design-system presentation.

## Deliberately deferred

Historical grouping consolidation, retention commands, consent-manager integration, high-volume pre-aggregation/caching, more themes/charts and any identity-based metric remain in the roadmap.
